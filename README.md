# 🔐 Verificador de Força de Senha

## 🎯 Objetivo do projeto

Este projeto tem como objetivo desenvolver uma aplicação web simples
capaz de analisar a força de uma senha informada pelo usuário.

A aplicação verifica algumas características da senha, como quantidade
de caracteres, letras maiúsculas, letras minúsculas, números e
caracteres especiais.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## 📚 O que foi aprendido

Durante o desenvolvimento do projeto, foram praticados conceitos
básicos de desenvolvimento web e programação, incluindo:

- Estruturação de páginas com HTML;
- Estilização de interfaces utilizando CSS;
- Manipulação do DOM com JavaScript;
- Criação e utilização de eventos;
- Estruturas condicionais;
- Validação de informações;
- Organização de arquivos em um projeto;
- Utilização do GitHub para armazenamento e documentação do projeto.

## 🔐 Relação com Segurança da Informação

O projeto está relacionado aos conceitos básicos de Segurança da
Informação, especialmente à importância da utilização de senhas
mais fortes para aumentar a segurança de contas e informações.

## 🚀 Possíveis melhorias

Como melhorias futuras, o projeto poderá incluir:

- Gerador automático de senhas;
- Botão para mostrar e ocultar a senha;
- Indicador visual da força da senha;
- Recomendações para criar senhas mais seguras.
